# Цагийн ажлын зарын самбар: тохируулах заавар

Үнэгүй ажиллана. Байгууллага зар илгээнэ, админ батална, оюутан зар сонгоод анкет илгээнэ. Анкет тухайн байгууллагын имэйл рүү очиж, таны Google Sheet-д хадгалагдана. Та утсандаа суулгасан админ апп-аас бүгдийг удирдана.

| Файл | Юу хийдэг |
|---|---|
| `index.html` | Оюутнуудад зориулсан зарын самбар ба анкет. Энэ линкийг оюутнуудад тараана. |
| `post.html` | Байгууллага зар илгээх маягт. Энэ линкийг байгууллагуудад өгнө. |
| `admin.html` | Нууц үгтэй dashboard: анкетууд, зар батлах, тохиргоо. Утсандаа апп болгон суулгана. |
| `apps-script/Code.gs` | Google Sheet-д бичдэг backend. |
| `config.js` | Apps Script-ийн URL оруулах газар. |

---

## 1. Google Sheet ба Apps Script (10 минут орчим)

> Script-ийг Sheet-ээс тусад нь script.google.com дээр үүсгэсэн бол `Code.gs`-ийн `SPREADSHEET_ID`-д Sheet-ийн ID-г тавина. Extensions → Apps Script-ээр үүсгэсэн бол хоосон үлдээнэ.

1. [sheets.new](https://sheets.new) хаягаар шинэ хүснэгт үүсгэнэ. Нэр нь жишээ нь «Цагийн ажлын бүртгэл».
2. Цэснээс **Extensions → Apps Script** сонгоно.
3. `Code.gs` доторх кодыг бүгдийг устгаад `apps-script/Code.gs` файлын агуулгыг хуулж тавина. **Save** (💾) дарна.
4. Зүүн талын ⚙️ **Project Settings** рүү ороод доод хэсгийн **Script properties → Add script property** дээр дарна:
   - **Property** = админы нэвтрэх нэр (жишээ нь `khuslee`), **Value** = нууц үг. Хамгийн багадаа 12 тэмдэгт, таахад хэцүү байх ёстой. Өөр админ нэмэх бол дахин нэг мөр нэмнэ.
   - `NOTIFY_EMAIL` (сонголттой): мэдэгдэл өөр имэйл рүү очих бол энд бичнэ. Хоосон орхивол таны Google имэйл рүү очно. Мэдэгдэл хэрэггүй бол `off` гэж бичнэ.
5. Editor руу буцаж ороод дээд хэсгийн функцийн жагсаалтаас `setup`-ийг сонгоод **Run** дарна.
   - «Authorization required» гарвал: **Review permissions**, өөрийн бүртгэлээ сонгоно. Дараа нь **Advanced → Go to … (unsafe)** дарж **Allow** хийнэ. Энэ бол таны өөрийн script тул аюулгүй.
   - Хүснэгтэд «Бүртгэл» гэсэн хуудас үүсэх ёстой.
6. Баруун дээд буланд **Deploy → New deployment** дарна:
   - ⚙️ дээр дарж **Web app** сонгоно.
   - Execute as: **Me**
   - Who has access: **Anyone**. Оюутнууд нэвтрэхгүйгээр бөглөхөд энэ тохиргоо заавал хэрэгтэй.
   - **Deploy** дарна. Гарч ирсэн **Web app URL**-ийг хуулна. Энэ нь `https://script.google.com/macros/s/…/exec` хэлбэртэй байна.

## 2. URL-ийг оруулах

`config.js` файлыг нээгээд хуулсан URL-ээ тавина:

```js
const API_URL = "https://script.google.com/macros/s/XXXX/exec";
```

## 3. GitHub Pages дээр байршуулах

1. [github.com/new](https://github.com/new) хаягаар шинэ repo үүсгэнэ. Нэр нь жишээ нь `tsagiin-ajil`, **Public** байна. Үнэгүй Pages зөвхөн public repo дээр ажилладаг. Кодонд нууц мэдээлэл байхгүй, нууц үг Google талд хадгалагддаг.
2. **Add file → Upload files** дарж энэ хавтасны бүх файлыг чирж оруулна: `index.html`, `admin.html`, `style.css`, `common.js`, `config.js`, `sw.js`, `manifest.webmanifest`, `icons/` хавтас. `apps-script/` болон `README.md`-ийг оруулах шаардлагагүй. **Commit changes** дарна.
3. Repo-ийн **Settings → Pages** руу орно. Source: **Deploy from a branch**, Branch: `main` / `(root)` гэж сонгоод **Save** дарна.
4. 1–2 минутын дараа линк гарна:
   - Анкет: `https://ТАНЫ-НЭР.github.io/tsagiin-ajil/`
   - Админ: `https://ТАНЫ-НЭР.github.io/tsagiin-ajil/admin.html`

Сонголттой: Apps Script-ийн Script properties-д `ADMIN_URL` = админ линкээ нэмбэл мэдэгдэл имэйлд тэр линк орж ирнэ.

## 4. Утсандаа апп болгон суулгах

- **iPhone:** Safari-аар админ линкээ нээгээд **Share (⬆️) → Add to Home Screen** дарна.
- **Android:** Chrome-оор нээгээд **⋮ → Add to Home screen** эсвэл **Install app** дарна.

Нэг удаа нэвтэрсний дараа 30 хоног нууц үг асуухгүй. Апп руу орох бүрд болон 60 секунд тутамд жагсаалт өөрөө шинэчлэгдэнэ.

## 5. Ашиглах

- Анкетын линкийг оюутнуудад тарааж болно: Facebook, группууд, QR код гэх мэт.
- Ажлын гарчиг, цалин, байршил, тайлбарыг админ апп-ын **«Ажлын мэдээллийг засах»** хэсгээс өөрчилнө. Бүртгэлийг хаахдаа мөн тэндээс хаана.
- Нэг утасны дугаараар дахин бөглөвөл шинэ мөр нэмэгдэхгүй, хуучин анкет нь шинэчлэгдэнэ.
- Бүх өгөгдөл Google Sheet-д байгаа. Тэнд шууд засаж, шүүж, Excel-ээр татаж болно. **id** багана нуугдсан байгаа, түүнийг бүү өөрчил.

## Код шинэчлэх үед

- **Code.gs өөрчилсөн бол:** Apps Script-д хадгалаад **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** дарна. URL өөрчлөгдөхгүй.
- **HTML/CSS өөрчилсөн бол:** GitHub дээр файлаа дахин upload хийнэ. Утсан дээрх апп дараагийн удаа нээхэд шинэчлэгдэнэ.
- **Нууц үг солих бол:** Script properties-д тухайн админы утгыг өөрчилнө. Тэр админы бүх төхөөрөмж автоматаар гарч, дахин нэвтрэх шаардлагатай болно.

## Аюулгүй байдал

- Нууц үг зөвхөн Google сервер талд шалгагддаг. GitHub дээрх кодонд нууц үг байхгүй.
- 5 удаа буруу оруулбал нэвтрэх 10 минут түгжигдэнэ.
- Sheet-ийнхээ хуваалцах тохиргоог **Restricted** хэвээр үлдээгээрэй. Web app нь таны эрхээр ажилладаг тул Sheet-ийг нээлттэй болгох шаардлагагүй.

## Зарын самбар ажиллах зарчим

1. Байгууллага `post.html`-ээр зар илгээнэ → Sheet-ийн «Зарууд» хуудсанд «Хүлээгдэж буй» төлөвтэй орно, танд мэдэгдэл имэйл ирнэ.
2. Админ апп → **Зарууд** таб → **Батлах**. Зар самбарт гарч, байгууллагад «нийтлэгдлээ» имэйл очно.
3. Оюутан зар сонгоод анкет илгээнэ (мэдээллээ байгууллагад илгээхийг зөвшөөрөх ёстой). Анкет байгууллагын имэйл рүү шууд очно.
4. Зар дүүрвэл **Хаах**. Байгууллагын утас, имэйл самбарт хэзээ ч харагдахгүй.

**Имэйлийн хязгаар:** энгийн Gmail бүртгэл өдөрт ~100 имэйл илгээнэ. Анкет бүр 2 имэйл (байгууллага + танд) зарцуулна. Хязгаар дуусвал анкет хадгалагдсаар, картанд «Байгууллагад илгээгдээгүй» гэж гарна — маргааш **Дахин илгээх** дарна. Анкет ихсэвэл Тохиргоо → Имэйл мэдэгдлийг унтрааж хязгаараа хэмнэнэ.
